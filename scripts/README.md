# scripts/

Standalone data-pull scripts. These are not part of the Next.js app and are not
run by the build — run them by hand when you want to refresh a dataset.

Note that the main pipeline that generates most of `data/*.ts` lives elsewhere
(see the `AUTO-GENERATED by` header on each file). Scripts here are self
contained and depend only on the Python standard library.

## fetch_bdc_income.py

Pulls per-quarter income-statement and non-cash-income figures for all 19 BDCs
from SEC EDGAR's XBRL company facts — net investment income, total investment
income, PIK income, accretion of discount, and declared distributions.

This is the data behind "PIK as a % of NII" and "can this BDC cover its cash
dividend out of cash income", neither of which the Schedule of Investments can
answer, since it is a balance sheet.

```bash
# 1. check the ticker -> CIK mapping looks right before pulling anything
python3 scripts/fetch_bdc_income.py --user-agent "Your Name you@firm.com" --resolve-only

# 2. pull it
python3 scripts/fetch_bdc_income.py --user-agent "Your Name you@firm.com"
```

Writes `out/bdc_income_quarterly.csv` (the data) and `out/bdc_income_tagmap.csv`
(which XBRL tag each number came from, per BDC — read this to see which filers
report PIK cleanly and which don't). Pass `--emit-ts` to also write
`data/bdc_income.ts` for the site.

Requires outbound access to `sec.gov`, and SEC requires a real contact email in
the User-Agent or it will reject the requests.

Run `python3 scripts/test_fetch_bdc_income.py` to exercise the extraction logic
offline — no network needed.
